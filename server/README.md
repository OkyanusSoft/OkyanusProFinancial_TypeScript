# الخادم المركزي — النظام المالي المتكامل v3.0

معمارية **Modular Monolith**: خادم Express واحد بحزم منفصلة (مزامنة، أنشطة تكيفية، مصادقة، تقارير) مع قاعدة **MySQL 8** ونظام **Migrations** مرقّم، وبث لحظي عبر **WebSocket**.

## التشغيل

```bash
cd server
cp .env.example .env        # عدّل بيانات الاتصال
npm install
npm run migrate             # إنشاء/ترميم كل الجداول تلقائياً (Idempotent)
npm start                   # http://localhost:4000  +  ws://localhost:4000/ws
```

## المزامنة المركزية اللحظية (عقد المزامنة)

- **دمج على مستوى السجل — الأحدث يفوز**: `POST /api/v3/sync/push` يستقبل `{deviceId, patches:[{coll, rows}]}` ويدمج كل صف بشرط `updated_at` الأحدث فقط (لا يُمحى سجل جهاز آخر أبداً).
- **Tombstones**: أي حذف يُسجَّل في `tombstones` بمفتاح فريد `(coll, record_id)` فينتشر مرة واحدة ولا يعود السجل.
- **الجيل Gen**: الاستعادة/إعادة التهيئة ترفع `generations.current` وتبث快照 كاملة، فتستبدل كل الأجهزة نسختها القديمة تلقائياً.
- **البث اللحظي**: كل عملية مقبولة تُبث فوراً عبر WebSocket لكل الأجهزة المتصلة ما عدا المصدر — ما يدخله الكاشير يظهر للمحاسب والمدير خلال ثوانٍ.
- **سحب تفاضلي**: `GET /api/v3/sync/pull?since=<seq>` يعيد العمليات الأحدث من سجل `sync_ops` للأجهزة المنفصلة.

## تحمل 100+ مستخدم متزامن

- حزمة اتصالات `mysql2` بحجم 40 مع طابور 200 + فهارس على `updated_at` و`(coll, record_id)`.
- الدمج يتم بجملة واحدة `INSERT … ON DUPLICATE KEY UPDATE` لكل دفعة داخل معاملة واحدة.
- معدل العمليات محدود (Rate Limit) لكل جهاز، والرسائل اللحظية عبر WebSocket بدون استطلاع.

## نظام Migrations

ملفات `migrations/*.sql` مرقّمة تُنفَّذ بالترتيب وتُسجَّل في `schema_migrations` (لا تُعاد أبداً).
- إضافة جدول: ملف جديد برقم تالٍ.
- إضافة/تعديل عمود: نمط `0005_alter_patterns.sql` (إجراءات شرطية آمنة للتكرار).

## المصادقة

`POST /api/v3/auth/login` → JWT (OAuth2 Bearer). شاشة تفعيل الأنظمة تتطلب `MASTER_PIN` المالك.
