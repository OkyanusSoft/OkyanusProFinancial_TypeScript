# OkyanusProERP 3.0 — نظام أوكيانوس للمحاسبة وإدارة الأعمال

نظام محاسبي وإداري متكامل من **شركة أوكيانوس سوفت — Okyanus Soft** ([okyanussoft.online](https://okyanussoft.online/))،
مصمم بنمط **Modular Monolith** مع فصل تام بين طبقات العرض ومنطق الأعمال والوصول إلى البيانات، وقاعدة بيانات **MySQL 8.4**.

## الوحدات الوظيفية
| الوحدة | المحتوى |
|---|---|
| لوحة التحكم | مؤشرات لحظية، رسوم تفاعلية، تنبيهات رقابية، بث الحركات |
| المخازن | الوحدات/المخازن/المجموعات/الأصناف + 6 سندات (افتتاحي، توريد، صرف، تحويل، تسوية، جرد) مع التراجع |
| المشتريات | الموردون وتصنيفاتهم، طلبات وعروض أسعار، فواتير **نقدي/آجل**، تقارير تحليلية |
| المبيعات | عملاء بحدود ائتمانية، عروض أسعار، فواتير ومرتجعات، تقارير يومية/شهرية/سنوية |
| الحسابات العامة | فترات مالية مقفلة بمحفزات، عملات وأسعار صرف، مراكز تكلفة، دليل **5 مستويات**، **حسابات تحليلية** مرتبطة بالمستوى الخامس، قيود متعددة العملات، ميزان مراجعة/ميزانية/قائمة دخل (IFRS) |
| إدارة النظام | مستخدمون وصلاحيات على مستوى الشاشة والزر والتقرير، إعدادات مالية، **قسم قاعدة البيانات** (اتصال MySQL، اختبار، تفعيل التراخيص، نسخ احتياطي) |

## التشغيل
```bash
cp .env.example .env        # DB_HOST, DB_PORT, DB_USER, DB_PASS, DB_NAME, JWT_SECRET
docker compose up -d mysql  # قاعدة البيانات + الترحيلات
npm install
npm run dev                 # الواجهة على http://localhost:5173
npm run build               # إنتاج dist/
npm run test                # اختبارات الوحدة والتكامل
```

## متغيرات البيئة
| المتغير | الوصف | الافتراضي |
|---|---|---|
| `DB_HOST` | عنوان خادم MySQL | `127.0.0.1` |
| `DB_PORT` | المنفذ | `3306` |
| `DB_USER` / `DB_PASS` | بيانات الدخول | — |
| `DB_NAME` | اسم القاعدة | `okyanus_erp_v3` |
| `JWT_SECRET` | سر توقيع الرموز | — |
| `BACKUP_PATH` | مسار النسخ الاحتياطي | `/var/backups/okyanus-erp` |

## الأمان
