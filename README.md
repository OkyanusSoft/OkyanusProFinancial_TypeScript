## نظرة عامة

نظام ERP مالي ومخزني متكامل يعمل بقاعدة بيانات **MySQL 8** بنمط **Modular Monolith** مع فصل طبقات (Presentation / Business Logic / Data Access)، ويعتمد **القيد المزدوج** وإقفال الفترات المالية ومبدأ الاستمرارية.

## الحسابات التحليلية (نقطة الابتكار)

حساب المستوى الخامس `11212 — نزلاء المستشفى` يُربط بشاشة الحسابات التحليلية؛ فيُضاف اسم لكل مريض هناك بدلاً من تضخيم دليل الحسابات، مع مطابقة تلقائية للإجماليات مع الأستاذ العام.

## الإجراءات المضمّنة في كل الشاشات

- **توليد أرقام وترميز** تلقائي (`PREFIX-السنة-####`) لكل سند وفاتورة ودليل، مع بادئات قابلة للتخصيص.
- **استيراد بيانات** جماعي (CSV) مع معاينة وتحقق من التكرار قبل الاعتماد + نموذج قابل للتنزيل.
- **التحقق من الصلاحية والتكرار**: إلزامية الحقول، منع تكرار الأكواد والأسماء، تحقق رقمي، فحص الحد الائتماني، ومنع الرصيد السالب.
- **الحذف والصيانة**: حذف ناعم إلى سلة محذوفات مع استعادة أو حذف نهائي.
- **التكامل المالي والمحاسبي**: الفواتير تولّد أثرها المخزني والذمم، والدفعات تولّد سندات قبض/صرف، والحسابات الوسطية قابلة لإعادة التوجيه.
- **إقفال الفترات**: حماية كتابة مطلقة على الفترات المقفلة.
- **قوائم وسجلات ديناميكية**: بحث فوري، تبويبات وقوائم منسدلة مرتبطة بالأدلة، عدّادات متحركة، وتصدير Excel (CSV) وPDF لكل تقرير.

```bash

npm run dev        # تشغيل بيئة التطوير (Vite + React + TypeScript)
npm run build      # بناء نسخة الإنتاج في dist/
```

## خطة التنفيذ (Sprints)

1. **Sprint 1**: قاعدة البيانات (ERD + محفزات التوازن والإقفال) والمصادقة والصلاحيات.
2. **Sprint 2**: المخازن — الأدلة والسندات الستة والتقارير الخمسة.
3. **Sprint 3**: المشتريات والمبيعات مع نمطي السداد والمرتجعات.
4. **Sprint 4**: الحسابات العامة — القيود والتحليلي وتقارير IFRS.
5. **Sprint 5**: إدارة النظام والإعدادات وقاعدة البيانات والنسخ الاحتياطي.
6. **Sprint 6**: UAT والتدريب والإطلاق.
